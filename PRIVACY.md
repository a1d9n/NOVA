# NOVA Privacy Policy

**Last updated: September 27, 2026**

This Privacy Policy explains what information NOVA collects and logs, why we collect it, how it is used, how it may be stored, and what choices you have.

NOVA is a Discord bot developed and operated independently from Discord Inc.

By using NOVA, you acknowledge that information may be processed and logged as described below.

## 1. What NOVA collects and logs

NOVA logs a significant amount of information because many of its features depend on records of what happened.

Depending on how you use NOVA, our logs and databases may contain:

### Discord account information

This can include:

* Discord user ID
* Username
* Display name
* Server nickname
* Avatar information
* Roles and role IDs
* Permission-related information
* Server membership information
* Account-related information that Discord makes available to the bot

### Server information

NOVA may store information about servers where it is installed, including:

* Server ID
* Server name
* Server icon information
* Channel IDs and names
* Role IDs and names
* Server owner information
* Server administrator information
* Server configuration
* NOVA settings
* Enabled or disabled features
* Security settings
* Moderation settings
* Ticket settings
* AI settings
* Memory settings
* Custom responses and server-specific configuration

### Messages and message content

NOVA may log and process messages that it can access through Discord.

Depending on the feature, this can include:

* Message content
* Message ID
* Author ID
* Channel ID
* Server ID
* Message timestamps
* Attachments
* Links
* Replies and referenced messages
* Information needed to understand the context of a conversation

NOVA may process message content even when the message is not an AI question if another NOVA feature needs access to it.

For example, message content may be processed by moderation, security, memory, logging, automation, or other systems.

### Commands and interactions

NOVA may log interactions with its commands and features.

These records can include:

* Command names
* Command options
* Button interactions
* Select menu interactions
* Modal submissions
* Slash command information
* User and server IDs
* Channel IDs
* Timestamps
* Whether the request succeeded or failed
* Error information
* Rate-limit information

This allows us to determine what happened when a feature fails or is abused.

### Moderation logs

If NOVA's moderation features are enabled, NOVA may record moderation events such as:

* Warnings
* Strikes
* Suspensions
* Bans
* Unbans
* Kicks
* Timeouts
* Deleted messages
* Moderation reasons
* Moderators responsible for an action
* Appeals
* Appeal decisions
* Related user and server information

Moderation records may remain after the original message or interaction is gone because they can be needed for moderation history, appeals, security, or abuse investigations.

### Security and anti-abuse logs

NOVA's security systems may generate detailed records when they detect suspicious activity.

These records may include:

* User IDs
* Server IDs
* Channel IDs
* Role changes
* Permission changes
* Member joins and leaves
* Large numbers of actions occurring in a short period
* Security detections
* Anti-raid events
* Anti-nuke events
* Suspicious configuration changes
* Rate-limit events
* Repeated failed actions
* Security warnings
* Automated security actions
* Information needed to investigate an incident

Security logs may be retained longer than ordinary activity logs when they are needed to investigate abuse or protect NOVA and its users.

### Tickets and support information

If you use NOVA's ticket or support features, NOVA may store information related to the ticket.

This may include:

* Ticket creator
* Ticket participants
* Ticket messages
* Ticket forms and answers
* Staff responses
* Ticket creation and closing times
* AI-generated ticket responses
* Ticket status
* Actions taken by staff
* Related server and channel information

Closed tickets may remain stored for moderation, support, security, auditing, or dispute resolution.

### AI requests

When you use NOVA's AI features, NOVA may log information about the request.

This may include:

* The message sent to the AI
* Conversation context needed to generate a response
* User ID
* Server ID
* Channel ID
* Selected NOVA feature or model
* Request timestamp
* Response status
* Error information
* Usage and rate-limit information
* Generated response
* Other technical information associated with the request

AI conversations may therefore be stored rather than existing only temporarily.

## 2. Why NOVA logs this information

NOVA does not log information simply because we want a record of everything.

Logging is used for specific operational purposes, including:

* Providing NOVA's features
* Maintaining conversation context
* Providing memory
* Moderation
* Security
* Anti-raid protection
* Anti-nuke protection
* Abuse prevention
* Investigating reports
* Handling appeals
* Debugging
* Diagnosing errors
* Investigating crashes
* Monitoring service health
* Detecting unusual activity
* Enforcing rate limits
* Preventing people from bypassing restrictions
* Maintaining server configuration
* Improving reliability
* Improving NOVA's AI systems
* Investigating security incidents
* Protecting NOVA and its users

Different information may be used for different purposes.

## 3. AI training and improvement

NOVA may use logged information to improve its AI systems and features.

This can include information such as:

* AI requests
* AI responses
* Conversation context
* Error cases
* Feedback
* Examples of incorrect or low-quality responses
* Other information needed to improve NOVA

If information is used for AI improvement, it may be reviewed or processed for that purpose.

We do not claim that every message sent to NOVA is manually reviewed or used for training.

The specific information used for AI improvement may depend on the feature, system, and development process involved.

## 4. What happens when you send a message to NOVA

When you send something to NOVA, it may pass through multiple systems.

For example:

1. Discord receives and delivers the interaction.
2. NOVA receives the information required for the feature.
3. NOVA may create logs about the request.
4. NOVA may send necessary information to an AI provider or another service.
5. NOVA may store the request, response, or related event in its own systems.
6. Additional security, moderation, memory, or logging systems may process the information.
7. Relevant records may remain stored while they are needed for their purpose.

Not every request goes through every step.

The exact processing depends on what feature you are using.

## 5. Memory

NOVA may provide memory features that allow information to be saved and used in later conversations.

Memory information can be stored separately from ordinary request logs.

Depending on the feature, a memory may contain information from:

* Messages
* Conversations
* User-provided information
* Server information
* Preferences
* Other information NOVA has been instructed or configured to remember

If NOVA provides a memory deletion or management feature, you can use that feature to manage information specifically saved as memory.

Deleting a memory does not necessarily delete every other record containing the same information.

For example, the same information could also exist in a moderation record, security log, support ticket, AI request log, or backup.

## 6. Files and attachments

If you send NOVA a file, image, document, or other attachment, NOVA may process and store information associated with it.

This may include:

* The file itself
* File name
* File type
* File size
* Attachment ID
* Message information
* User and server information
* Information extracted from the file
* AI analysis or responses related to the file

Files may be retained while they are needed by the feature that processed them or for related operational purposes.

Do not send NOVA files containing passwords, private keys, financial information, or other sensitive information unless the feature specifically requires it.

## 7. Data retention

NOVA does not keep all information for the same amount of time.

Retention can vary depending on the type of information, why it was collected, which feature created it, and whether the information is still needed.

Information may be kept while it is needed to:

* Provide a feature
* Maintain conversation context
* Maintain memory
* Keep moderation records
* Investigate abuse
* Protect NOVA and its users
* Troubleshoot problems
* Maintain security
* Resolve disputes
* Improve NOVA
* Meet applicable legal requirements

Some information may be removed when it is no longer needed.

Other information may remain stored for longer when there is an ongoing reason to keep it.

Backups and other systems may also contain information after it has been removed from active systems. Those copies may remain until they are naturally replaced or are otherwise no longer needed.

NOVA does not promise a single retention period for all information.

## 8. Deleting your information

NOVA may provide deletion or management controls for certain types of information.

For example, if a feature provides a way to delete saved memory, that control can be used to remove the applicable memory.

Not every type of information has a user-facing deletion control.

Some logs, moderation records, security records, tickets, technical records, or backups may not be directly deletable by individual users because they may be needed for security, abuse prevention, investigations, service operation, or other legitimate purposes.

If you have a privacy-related deletion request that is not covered by an available NOVA control, you can contact the NOVA team through the official support channels.

A deletion request does not necessarily mean every record containing the same information can be immediately removed.

Deleting information from NOVA does not delete information held by Discord or independent third-party services.

## 9. NOVA data vs. Discord data

NOVA and Discord are separate services.

NOVA may receive certain information from Discord because NOVA operates as a Discord bot. NOVA's storage of that information is separate from Discord's own systems.

Deleting information from NOVA does not delete the corresponding information from Discord.

Likewise, deleting a Discord message, account, server, or other Discord data does not necessarily remove information that NOVA previously stored in its own systems.

Discord controls its own data and privacy practices. NOVA does not control how Discord stores or processes information on its platform.

## 10. Server administrators and other users

If you use NOVA in a Discord server, other people in that server may be able to interact with information processed by NOVA.

For example, server moderators may have access to moderation records or ticket information.

Server administrators can also configure NOVA features that affect how information is processed.

NOVA cannot control what a server administrator does with information they can independently access through Discord or other server tools.

## 11. Third-party AI and infrastructure providers

NOVA may send information to third-party services when those services are necessary to provide a feature.

These services may include:

* AI providers
* Hosting providers
* Database providers
* Logging and monitoring providers
* Networking providers
* Storage providers
* Other infrastructure services

The information sent depends on the feature being used.

Third-party providers may process information under their own privacy policies and terms.

## 12. Security

We use technical and administrative measures intended to protect NOVA's stored information.

However, no online service can guarantee that information will never be accessed, lost, altered, or disclosed because of a security incident.

If NOVA experiences a security incident, we may investigate it, restrict affected systems, preserve relevant logs, and take other appropriate steps.

Security logs may be particularly important during an investigation and may therefore be retained longer than ordinary logs.

## 13. Information we do not want from you

Do not intentionally send NOVA:

* Passwords
* Discord tokens
* Private API keys
* Authentication codes
* Payment card numbers
* Private encryption keys
* Recovery codes
* Other credentials
* Highly sensitive personal information that NOVA does not need

NOVA's logging systems may record information that you voluntarily send to the bot.

If you accidentally send sensitive information, take appropriate steps to change or revoke it.

## 14. Your rights and choices

Depending on where you live and which laws apply, you may have rights regarding personal information.

These may include rights to:

* Request access to certain information
* Request correction of inaccurate information
* Request deletion
* Ask how information is being used
* Object to certain processing
* Request information about data retention

The availability of these rights depends on applicable law.

Contact the NOVA team through the official support channels if you want to make a privacy request.

## 15. Children's privacy

NOVA is a general-purpose Discord bot and is not specifically designed for children.

NOVA does not intentionally request unnecessary personal information from children.

NOVA operates through Discord, so Discord's own age requirements and policies also apply to anyone using NOVA.

If you believe NOVA has collected information that it should not have collected, contact the NOVA team through the official support channels so the situation can be reviewed.

## 16. International processing

NOVA and the services it uses may process information in countries other than the country where you live.

The location of processing can change as NOVA's infrastructure and service providers change.

## 17. Changes to this Privacy Policy

NOVA may update this Privacy Policy when its features, infrastructure, logging practices, or data handling change.

When significant changes are made, the date at the top of this policy will be updated.

We may also announce significant changes through NOVA's official channels.

## 18. Contact

For privacy questions, deletion requests, data concerns, or security reports, contact the NOVA team through the official NOVA support channels.

Please do not include passwords, Discord tokens, private API keys, or other sensitive credentials in your message.
